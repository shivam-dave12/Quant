BTC HFT Live-Learning Bot v5.1 — config.py consolidation audit

Change request:
- Apart from API keys and secrets, all settings must be in config.py.

Result: PASS

Implemented changes:
1. btchft/config.py is now the single source of truth for all non-secret configuration:
   - trading_mode
   - allow_live
   - allow_unvalidated_bootstrap_live
   - auto_promote_model
   - delta_symbol
   - delta_testnet
   - data lake paths
   - model/bootstrap paths
   - cost assumptions
   - live-learning and promotion gates
   - latency limits
   - risk limits
   - CLI output/status defaults

2. .env.example now contains only:
   - DELTA_API_KEY
   - DELTA_SECRET_KEY

3. Runtime code no longer reads non-secret values from environment variables.
   The only environment reads are inside btchft/config.py::load_delta_credentials(), and those reads are limited to API credentials.

4. CLI examples and README were updated to instruct operators to edit btchft/config.py instead of passing runtime mode/risk/model settings via environment variables.

5. Tests were updated to instantiate Settings(...) directly instead of monkeypatching runtime environment variables.
